## 4. สิ่งที่ตัดสินใจแล้ว (โดยผู้ใช้)

### 4.1 แบบจำลองหลายแก้ว
คาเฟอีนรวม ณ เวลา t = ผลรวมของแต่ละแก้ว:

A(t) = Σᵢ Dᵢ · e^(−kₑ (t − tᵢ))  สำหรับแก้วที่ tᵢ ≤ t

"เวลาที่นอนได้" = เวลาแรกหลังแก้วสุดท้ายที่ A(t) ≤ เกณฑ์

กรณีคาเฟอีนต่ำกว่าเกณฑ์ตั้งแต่หลังแก้วสุดท้าย (เช่น Decaf): แสดงข้อความ "คาเฟอีนต่ำกว่าเกณฑ์ตั้งแต่ดื่ม — นอนได้ทุกเมื่อ" แทนเวลา และกราฟ A แสดงช่วงอย่างน้อย 24 ชม. จากแก้วแรก *(ผมตัดสินใจ)*

### 4.2 เกณฑ์ "นอนได้"
- **เกณฑ์หลัก 50 mg** — จาก Gardiner et al. (2024, *Sleep*): กาแฟ 100 mg ดื่มก่อนนอน 4 ชม. ไม่รบกวนการนอนอย่างมีนัยสำคัญ → แปลงด้วยแบบจำลองได้เหลือ ≈ 57 mg ตอนเข้านอน
- **เส้นเสริม 30 mg (เกณฑ์เข้มงวด)** — จาก Gardiner et al. (2023, *Sleep Medicine Reviews*, meta-analysis): กาแฟ 107 mg ควรดื่มก่อนนอน ≥ 8.8 ชม. → เหลือ ≈ 31 mg แสดงเป็นเส้นประจางในกราฟ A **ไม่ใช้คำนวณเวลานอนหลัก**

### 4.3 กราฟ
- **กราฟ A (หลัก, แสดงก่อน):** เส้นเดียวของ A(t) จากเวลาแก้วแรกถึงหลังเวลานอนได้, เส้นประเกณฑ์ 50 mg, เส้นประจาง 30 mg, เส้นแนวตั้ง + ป้าย "นอนได้ HH:MM"
- **กราฟ B (ที่สอง):** พื้นที่ซ้อนสี แยกคาเฟอีนที่ค้างจากแต่ละแก้ว ผลรวมของชั้นคือเส้นของกราฟ A — ใช้อธิบายว่าคาเฟอีนรวม "คือผลรวมของพจน์" (เชื่อมกับ Series)
- ตัวอย่างอ้างอิงที่ผู้ใช้เลือกไว้: `.superpowers/brainstorm/.../content/graph-style.html` แบบ A และ B

### 4.4 หัวข้อคณิตศาสตร์: Sequence & Series
1. **ลำดับเรขาคณิต:** กาแฟ 1 แก้ว เมื่อผ่านไป n ครึ่งชีวิต เหลือ aₙ = D·(½)ⁿ — แสดงเป็นตาราง n = 0…6 พร้อมเวลาจริง
2. **อนุกรมเรขาคณิต + การลู่เข้า (สะสมข้ามวันช่วงสอบ):** ถ้าดื่มแบบเดิมทุกวัน ปริมาณที่ค้าง ณ เวลานอนของวันที่ n คือ
   Sₙ = B · (1 − rⁿ)/(1 − r), r = e^(−24·kₑ), B = A(เวลาที่ตั้งใจจะนอน) จากวันเดียว *(ผมตัดสินใจ: ใช้เวลาที่ผู้ใช้ตั้งใจจะนอน ไม่ใช่เวลานอนได้ — ถ้าใช้เวลานอนได้ B จะ ≈ 50 mg เสมอ ตารางจะไม่เปลี่ยนตาม input)*
   ลู่เข้าสู่ S∞ = B/(1 − r) เพราะ |r| < 1 — แสดงตารางวันที่ 1…7 เทียบ (ก) ผลรวมสะสมด้วย loop (partial sums แบบ Lab4) กับ (ข) สูตรปิด และค่าลิมิต พร้อมสรุปเป็นภาษาคนว่า "สะสมเพิ่มเล็กน้อยแล้วคงที่ ไม่พุ่งไปเรื่อย ๆ" (ผู้ใหญ่ทั่วไป r ≈ 0.033 เพราะ 24 ชม. ≈ 5 ครึ่งชีวิต จึงสะสมเพิ่มเพียง ~3%; ผู้สูงอายุ r สูงกว่าและสะสมมากกว่า — เป็นประเด็นวิเคราะห์ผลที่ดี)
   ส่วนนี้ **ใช้แสดงผลเท่านั้น** ไม่เปลี่ยนเวลานอนได้ของหัวข้อ 4.1

### 4.5 หัวข้อคณิตศาสตร์: Probability (Monte Carlo)
- คำถามที่ตอบ: "**มีโอกาสกี่ % ที่คาเฟอีนจะต่ำกว่า 50 mg ภายในเวลาที่ตั้งใจจะนอน**"
- สุ่ม N = 10,000 ครั้ง ด้วย `numpy` (fixed seed เพื่อให้ผลซ้ำได้ตอนสาธิตและทดสอบ)
  - ปริมาณคาเฟอีนแต่ละแก้ว ~ Uniform(low, high) จาก `COFFEES`
  - half-life ของบุคคล ~ **log-normal ที่มี median = t½ จากแบบจำลอง (น้ำหนัก/อายุ) ของผู้ใช้** แล้วตัดให้อยู่ในช่วง 1.5–9.5 ชม. (NCBI Bookshelf NBK223808) *(ผมตัดสินใจ: เพื่อให้ผลความน่าจะเป็นสอดคล้องกับเวลานอนหลัก และยังสะท้อนผลของอายุ ≥ 65; σ ของ ln t½ ≈ 0.35 ให้ผู้สร้างปรับได้ แต่ต้องอธิบายใน markdown)*
  - เนื่องจากกาแฟส่วนใหญ่มี low = high ความไม่แน่นอนส่วนใหญ่จึงมาจาก half-life — ให้ระบุข้อนี้ใน markdown
- ผลลัพธ์: % ที่นอนได้ตามเวลาที่ตั้งใจ (ความน่าจะเป็นเชิงประจักษ์ = จำนวนครั้งที่สำเร็จ / N) และฮิสโทแกรมของ "เวลาที่นอนได้" จากการสุ่ม
- ต้องเพิ่ม input **เวลาที่ตั้งใจจะนอน** (ใช้ในส่วนนี้)

### 4.6 Input / Output
- **Input:** น้ำหนัก, อายุ, จำนวนแก้ว, แต่ละแก้ว (หมายเลขกาแฟ + เวลา; ถ้ามีช่วง low–high ให้เลือกแบบเดิม), เวลาที่ตั้งใจจะนอน — ตรวจ input ผิดและถามใหม่แบบโค้ดเดิม
- **Output (เรียงตามลำดับการสาธิต):** ตารางสรุปแก้วที่ดื่ม → ค่า PK (Vd, CL, t½, kₑ) → **เวลานอนได้ (50 mg)** และเวลาตามเกณฑ์เข้มงวด (30 mg) → กราฟ A → กราฟ B → ตาราง Series → ผล Probability + ฮิสโทแกรม → ข้อความเตือนเดิม

### 4.7 การทดสอบ 3 กรณี
อยู่ในเซลล์แยก เรียกฟังก์ชันด้วยค่าคงที่ (ไม่ใช้ `input()`) แสดงผล + `assert` กับค่าที่คาด:
1. **วันปกติ:** 1 แก้วตอนเช้า
2. **ช่วงสอบ:** 60 kg, อายุ 20, Drip 08:00 (95 mg) + Drip 13:00 (95 mg) + Americano 2 shots 17:00 (126 mg) → นอนได้ **03:01** (50 mg) / **06:37** (30 mg) — ทดสอบส่งปริมาณ mg ตรง ๆ (ใช้ค่า low ของ Drip) assert ตรงนาที *(ผมตัดสินใจ)*
3. **กรณีขอบ:** ผู้สูงอายุ (อายุ ≥ 65, กำจัดช้ากว่า) ดื่ม Cold Brew — แสดงว่าเวลานอนได้ช้ากว่าคนอายุ 20 ที่ดื่มเท่ากัน และ % ใน Probability ต่ำกว่า *(ผมตัดสินใจ: ไม่ใช้ Decaf เป็นกรณีทดสอบหลัก แต่ข้อความ "นอนได้ทุกเมื่อ" ต้องทำงาน)*
